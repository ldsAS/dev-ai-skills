## 三、建議實作前補進計畫

### N1　摘要裡的區段與日期必須來自解析結果

2.4 節要求成功的 Antigravity 列包含「版號、canonical URL 與實際採用的 `Antigravity 2.0` 區段」，但沒有規定區段這個值從哪裡來。

如果實作只是在版本旁邊印一個常數字串，那麼即使 getter 接錯（例如仍在用舊的全文比對，或測試 stub 直接回傳版本），摘要照樣會寫出「Antigravity 2.0」。這正是 R4 想排除的情況：**驗收證據不能依賴「程式接線正確」這個待驗證的前提。**

建議在 2.4 節補一句：

- 區段名稱與被選中那一筆的**發行日期**，都從 parser 的回傳結果取得，例如 `2.18.1（September 28, 2026；## Antigravity 2.0）`。有日期，人工一眼就能對照官方 changelog，確認選到的是哪一筆；
- 測試表的「每輪版本摘要」補一例：getter 只回傳版本字串（現有 stub 的形狀）時，摘要**不得**出現區段或日期。

getter 要改成回傳結構化結果、還是由 parser 另外提供，交給實作決定；既有測試大量以 `return_value="2.8.1"` 這種形式 stub 版本 getter，選擇時要考慮相容性。

### N2　寬辨認條件要能接住沒有 `v` 前綴的版本標題

修訂後的 2.2 第 3 點把「以 `[v` 或 `v<數字>` 起始，或含指向 `/releases` 的連結」當成候選。這是照我第一輪 R1 的建議寫的，而那個建議本身有漏洞：

```markdown
### 2.19.0
### [2.19.0](/download#antigravity-app)
```

這兩種寫法都不會被辨認成候選，會被當成一般功能標題略過，結果仍靜默回傳 2.18.1。

建議改成：**H3 內容符合 `^\[?v?\d+\.\d+`，或含指向 `/releases` 的連結**，就算候選。

我對現行文件四個區段全部的非發行 H3 跑過這個條件，**命中 0 筆**：沒有任何功能標題以數字、`[數字` 或 `v數字` 開頭（SDK 的 `### Google Antigravity SDK release 0.1.2 updates` 不在行首）。所以放寬後不會誤判，重現指令見第六節。

失敗測試表的「無連結的新版 `### v2.19.0`」請一併加上 `### 2.19.0` 一例。

## 四、實作時處理

### N3　定義「安全文字」；同樣的風險在現有程式已經存在

2.2 第 2 點與測試表都要求 H2 診斷「以安全文字呈現，不得產生額外的 CI 訊號標記」，但沒有定義什麼是安全文字。實作時請寫明具體做法，例如把 `[SIGNAL:` 中和掉並限制長度，再用測試鎖住。

另外，這不是新程式才有的風險。`monitor_ci_policy.analyze_report()` 對整份報告做**子字串**搜尋，而現有的 `context_for()` 會把官方原文的摘錄原樣放進報告。我用現行程式實測：

| 輸入 | `analyze_report()` 結果 |
| :--- | :--- |
| 官方原文含 `.claude/demo/ ... [SIGNAL: CHECK_FAILED]`，其摘錄出現在新增 token 的前後文裡 | `failure: True`、`should_fail: True`、`issue_kinds: ['update', 'failure']` |

這種注入只能**多報**（假的失敗或假的異動，會轉紅、開 issue），不能把真的失敗藏起來；baseline 步驟另有 `git diff --quiet` 保護，所以風險低。npm 的版本字串也是未驗證就印進報告。

根本的修法是讓 `analyze_report()` 只認**獨立成行**的訊號。這要改 `monitor_ci_policy.py` 與相關測試，建議**不併入本批**，登記在第 7 節作為後續項即可。本批只需讓新增的 H2 診斷不擴大這個攻擊面。

### N4　失敗訊息要指出是哪一筆記錄

修訂後的規則要求產品區段的所有候選都通過驗證，這是刻意的取捨，我同意。但它也意味著：官方只要修改一筆很舊的記錄（例如把 v2.0.1 的日期改錯），監控就會轉紅，直到 parser 或上游修正為止。

2.2 第 6 點目前只要求例外「帶來源與原因」。建議實作時讓例外訊息包含**觸發失敗的標題原文（經 N3 的安全處理）與行號**，維護者看報告就能直接定位，不必重抓全文。

```bash
# N2：現行文件中，以數字／[數字／v數字 開頭、但不是發行標題的 H3（預期 0 筆）
curl -sSL https://antigravity.google/docs/changelog.md -o changelog.md
python -X utf8 - <<'EOF'
import re
t = open("changelog.md", encoding="utf-8").read()
sec, hits = None, 0
for line in t.split("\n"):
    if line.startswith("## "):
        sec = line[3:]
    elif line.startswith("### ") and not line.startswith("### [v") and re.match(r"### \s*\[?v?\d+\.\d+", line):
        hits += 1
        print(sec, "|", line[:100])
print("non-release hits:", hits)
EOF
```
