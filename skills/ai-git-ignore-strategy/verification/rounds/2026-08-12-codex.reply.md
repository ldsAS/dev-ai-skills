## 修正一：check_updates.py 的 Windows 輸出編碼

### 實際重現

未設定 `PYTHONUTF8` 時執行：

```powershell
python scripts/check_updates.py --coverage
```

原本會先在 `↔` 觸發 `UnicodeEncodeError: 'cp950' codec can't encode character`，進入例外處理後又因輸出 `❌` 再崩潰一次。設定 `$env:PYTHONUTF8='1'` 後可完成，證明檢查邏輯本身沒有失敗，問題只在終端輸出編碼。

### 修法與邊界

在 imports 後對 `sys.stdout`、`sys.stderr` 呼叫受 `hasattr(..., "reconfigure")` 保護的 UTF-8 `reconfigure`。作法與 `b2fc74e` 對 `verify_gitignore_template.py` 的修正一致。

這不是新的 AI 工具路徑事實，不需要新增 CLAIM；也不會改寫 baseline 或改變 45 條自動監控／2 條盲區的結果。

## 修正二：generic 版 YAML 範例的 Markdown 邊界
