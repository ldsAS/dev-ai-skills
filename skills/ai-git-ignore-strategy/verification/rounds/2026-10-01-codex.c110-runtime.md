## 方法與證據

每次使用獨立暫存空白工作區；registry 對照共用一個暫存 Git repo，以固定工作區只切換登記檔。以 `agy -p <prompt> --mode plan --output-format json|stream-json --log-file <task-temp>/<label>.log --print-timeout 120s` 執行，host timeout 150 秒。prompt 只給技能名稱，要求從 active available-skills catalog 取用；不提供驗證碼、不准搜尋檔案系統、執行 terminal、瀏覽或使用其他技能。探針 SKILL.md 的 frontmatter 與指令只要求回傳該次隨機碼。

兩個全域候選同時各放一個**不同名稱**的 probe，排除同名污染；另有沒有 probe 的陰性，以及移除 probe 的對照。三組名稱／碼與逐次輸出、exit、秒數、log／stdout SHA、實際工具事件保存在 [證據 JSON](./2026-10-01-codex.c110-runtime-evidence.json)。10 次 prompt 呼叫均 exit 0：
