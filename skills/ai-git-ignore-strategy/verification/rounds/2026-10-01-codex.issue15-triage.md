## 2. 逐項分類

### `.mcp.json`：正式 workspace 設定用途，不能借用 Claude 主張完成 Copilot 分類

[Migrate MCP servers](https://code.visualstudio.com/docs/copilot/customization/overview#_migrate-mcp-servers) 明寫遷移到 **“portable workspace .mcp.json file”**，或 user `$COPILOT_HOME/mcp-config.json`。操作需選定 Agent Host，再選 MCP 遷移；編輯器依目前 harness 檢查相容性，無法遷移的 server 留在來源設定。遷移保留啟用狀態，來源與目的檔不會持續同步，文件要求使用者核對目的檔。

**分類：正式設定／遷移機制。** 這裡不是任意命名範例或無關字串，也不是對話紀錄／暫存。只能支持此文件所述 Agent Host、目前 harness 及相容性條件下的 workspace 用途，不能推論所有 Copilot surface／舊版共用相同 schema。本輪未取得此功能最早支援版本，不把「本來源第一次抽到」當作「產品今天才新增功能」。

報告命中 **C-61**，是因其路徑也叫 `.mcp.json`；C-61 實際描述 **Claude Code**，不構成這次 Copilot 用途的取證。需要的是分開記錄各工具的適用範圍。現行五版已允許 repo 根目錄 `.mcp.json`，不需新增放行或排除。是否分享實際設定內容仍依用途與內容判斷，不能由 portable 一字推定每一份檔案都適合直接提交。

### `AGENTS.md`：正式跨工具指令格式；C-50／C-109 是錯誤跨工具歸屬

[Agent Skills vs custom instructions](https://code.visualstudio.com/docs/copilot/customization/agent-skills#_agent-skills-vs-custom-instructions) 表格將 custom instructions 的格式列為 **“Multiple formats, such as AGENTS.md and .github/copilot-instructions.md”**。它是在比較 skills 與 instructions 的用途、載入時機與可攜性，不是介紹自動產生的垃圾檔。

**分類：正式指令格式的說明／既有用途佐證。** 進一步核對 [VS Code custom instructions](https://code.visualstudio.com/docs/copilot/customization/custom-instructions)：`AGENTS.md` 是跨 agent 的專案指引格式；可用性及 discovery 依選定 harness，Local agent 也有設定控制。不能把單一表格推成每個 session 都一定載入。

報告命中 **C-109（Claude Code）與 C-50（Antigravity）**。這不是本頁支持或推翻了它們，而是 matcher 沒有工具 scope、只比對相同名稱。根目錄 `AGENTS.md` 五版均 ALLOWED，不需範本變動。

### `copilot-instructions.md`：原文是 `.github/` 內的正式共享指令檔

同一表格及其後段落共有兩次 `.github/copilot-instructions.md`，並舉 VS Code 與 Copilot CLI 可分享 repository 指令的用法。原文同時要求核對不同 experience 支持的位置與 activation 規則。

**分類：正式機制的文件示例／佐證，非使用者隨意取名。** 抽取器只輸出 basename `copilot-instructions.md`，但兩處原文完整位置都是 `.github/copilot-instructions.md`；沒有本輪新增「repo 根目錄直接放此檔」的證據。命中 C-70 的用途相符，但最終判定依完整上下文，不依 token 猜路徑。五版 `.github/copilot-instructions.md` 均 ALLOWED，不需範本變動。

## 4. 為什麼出現這些訊號，真正待修的是什麼

### 偵測本身有觸發依據，跨來源同名不證明搬移

獨立對照 bot 前的 `3816ac7`，三個 token 確實不在各自的 Copilot source entry；bot 在 `229bab6` 加入它們。這是正確的**逐來源詞彙新增**。當日完整 live-run 已與合併後 372 token 相符，不需要再手動寫入 baseline。

但 `3816ac7` 的其他 source 已有同名 token：`.mcp.json` **5 個來源**、`AGENTS.md` **15 個**、`copilot-instructions.md` **3 個**。這些數字與 bot 的跨來源註記一致，只證明同字串存在；我們沒有上游編輯歷史足以證明「複製／搬移」，更不能用 Claude／Antigravity 語意自動替 Copilot 分類。

### 已重現的問題與對應既有計畫

| 問題 | 可重現原因 | 後續歸類／反例 |
| :--- | :--- | :--- |
| 跨工具誤命中 | `load_claims()` 不保存工具章節，`claims_for_token(token, claims)` 無來源／工具參數。`AGENTS.md` 固定回 C-109／C-50，`.mcp.json` 回 C-61 | **M2 §3.5**。Copilot 來源不應因同名宣告 Claude／Antigravity 主張受影響；同一 token 仍須保留為 Copilot 待分類候選，不能因移除錯誤 mapping 而靜音 |

```powershell
gh issue view 15 --json state,comments

@'
import importlib.util, hashlib, subprocess, json
s = importlib.util.spec_from_file_location('m','scripts/check_updates.py')
M = importlib.util.module_from_spec(s); s.loader.exec_module(M)
old = json.loads(subprocess.check_output(['git','show','3816ac7:scripts/last_checked.json']))
cases = [
    ('copilot/customization','https://code.visualstudio.com/docs/copilot/customization/overview',['.mcp.json']),

for key, url, tokens in cases:
    raw = M.fetch(url); text = M.normalize(raw)
    print(key, len(raw.encode()), hashlib.sha256(raw.encode()).hexdigest())
    for token in tokens:
        print('context:', M.context_for(text, token))
        matches = [(a,b) for t,a,b in M.iter_token_matches(text) if t == token]
        print('matches:', matches, 'claims:', [c['id'] for c in M.claims_for_token(token,M.load_claims())])
        print('single segment:', M.is_single_segment(token))
        print('previous same-name sources:', [k for k,v in old['sources'].items()
              if k != key and any(M._norm_path(t) == M._norm_path(token) for t in v['tokens'])])
        for a,b in matches: print(text[max(0,a-1100):b+1500])
print(M.extract_tokens('AGENTS.md .github/copilot-instructions.md .mcp.json'))
'@ | python -X utf8 -B -
```
