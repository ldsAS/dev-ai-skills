## 三、R1（建議實作前修正）：`.agents/rules.json` 可引用 repo 外路徑

官方 [rules 頁](https://antigravity.google/docs/rules.md)「Sharing rules across projects」一節的範例：

```json
{
  "inherits": [
    { "path": "../shared-config/.agents/rules.json" }
  ],
  "entries": [
    { "path": "../shared-rules", "exclude": ["deprecated_rules.md", "legacy/"] },
    { "path": "rules", "include_only": ["frontend/react.md"] }
  ]
}
```

所以提交出去的 `rules.json` 可能：

1. 引用**隊友沒有的兄弟目錄**（`../shared-config`、`../shared-rules`）——規則在他們的環境會解析失敗；
2. 寫入**絕對路徑**——暴露個人的目錄結構。

計畫 4.1 的註解只寫「登記巢狀規則檔與共用規則設定」，帳本 C-41 的新列也沒有提到這一點。

**我仍同意預設放行。** 它的主要用途是登記 repo 內的巢狀規則（範例第三筆 `"path": "rules"`），擋掉的話，已提交的 `.agents/rules/<sub>/*.md` 會被靜默忽略，這個代價比較大。

**但建議比照 C-83 對 `.claude/launch.json` 的殘留風險寫法**，在範本註解與帳本補上：

```gitignore
# 登記巢狀規則檔；不提交的話，已提交的 .agents/rules/<sub>/*.md 不會被載入。
# ⚠️ 官方範例可用 ../ 引用 repo 外的共用規則：隊友需有相同目錄結構。
#    若含絕對路徑，可能暴露個人目錄，提交前請確認。
!.agents/rules.json
```

這會改到範本註解和帳本措辭，所以建議在實作**前**定案，避免實作完再返工。

### R2　補「被白名單打開的子目錄」回歸案例

計畫 4.1 寫「最終順序以實際 Git 邊界驗證為準」，代表規則順序可能調整。若調整後 `!.agents/rules/`、`!.agents/skills/`、`!.agents/plugins/` 這類白名單落在 `ORIGINAL_REQUEST.md` 的排除規則**之後**，底下的 prompt 檔就會被重新放行。

## 五、一個建議寫進帳本的判斷理由

建議把這個理由寫進 C-42 或新列，免得之後被當成疏漏而被「對稱化」。

# R2：以計畫的規則位置驗證被白名單打開的子目錄（預期五版 20 次全部 IGNORED）
import re, io, subprocess, tempfile, pathlib, os
ADD = "!.agents/AGENTS.md\n!.agents/GEMINI.md\n!.agents/rules.json\n**/.agents/**/ORIGINAL_REQUEST.md\n"
ANCHOR = ".agents/**/ORIGINAL_REQUEST.md\n"
cases = [".agents/rules/ORIGINAL_REQUEST.md", ".agents/skills/foo/ORIGINAL_REQUEST.md",
         ".agents/plugins/ORIGINAL_REQUEST.md", ".agents/agents/x/ORIGINAL_REQUEST.md"]
for v in ("antigravity", "claude", "codex", "generic", "vscode"):
    s = io.open(f"skills/ai-git-ignore-strategy/{v}/SKILL.md", encoding="utf-8").read()
    tpl = [b for b in re.findall(r"(?ms)^```[a-zA-Z]*\n(.*?)^```$", s) if ".claude/*" in b][0]
    tpl = tpl.replace(ANCHOR, ANCHOR + ADD, 1)
    d = tempfile.mkdtemp(); env = os.environ.copy()
    env["GIT_CONFIG_NOSYSTEM"] = "1"; env["GIT_CONFIG_GLOBAL"] = os.devnull
    subprocess.run(["git", "init", "-q", d], env=env, stdout=subprocess.DEVNULL)
    pathlib.Path(d, ".gitignore").write_text(tpl, encoding="utf-8")
    res = ["IGNORED" if subprocess.run(["git", "-c", f"core.excludesFile={os.devnull}", "check-ignore",
                                        "--no-index", "-q", "--", p], cwd=d, env=env).returncode == 0
           else "ALLOWED" for p in cases]
    print(v, res)
