## 二、做得好、我要沿用的三件事

### 2-1　verifier 的環境隔離（`GIT_CONFIG_NOSYSTEM` / `GIT_CONFIG_GLOBAL` / `core.excludesFile`）

**這是本輪最有價值的改動，而且理由比你寫的還強。**

官方 settings 文件明載：Claude Code 第一次寫入 `.claude/settings.local.json` 時，會**自動把 `**/.claude/settings.local.json` 加進使用者的 global git excludes**。也就是說：

> 在任何跑過 Claude Code 的維護者機器上，就算範本的 C-97 規則被整條刪掉，`verify_gitignore_template.py` 也可能照樣綠燈。

這是「測試在特定機器上靜默失去效力」——正是 C-89 那條教訓（沒被驗證過的斷言等於沒有斷言）的變形，而且更隱蔽，因為它不是斷言寫錯，是**環境幫它作弊**。

我實測了這台機器目前沒有設 `core.excludesFile`，所以這次沒有被實際掩蓋，但那是運氣，不是設計。**這個隔離應該視為 verifier 的永久要求。**

### 2-2　逐條 mutation，而且只測該條的案例

「移除一條時只測該條的行為案例，避免把不相關失敗算成保護有效」——這個細節很重要。整批跑然後看到「有紅」就宣告保護有效，是很常見的自我欺騙。我照你的作法重跑，6/6 都對。

### 2-3　邊界克制

- 保留 C-100～C-102 給未合併的 PR #14，不重編。
- 不觸發遠端 workflow，理由寫得很清楚（見第五節，這點你糾正了我）。
- 不關 #15／#16，並且說明「本輪範本修正不會讓排程變綠」——正確，見第六節。
- `install.ps1` 測試如實聲明「首次裸命令失敗，顯式 `Import-Module` 後才通過，**不宣稱裸命令通過**」。這種不含糊的負面回報，比一句「測試通過」有用得多。

## 三、需要處理的 3 件事

### F1（要修）：C-105 有主張，但監控零涵蓋，而報表會說有涵蓋

`.claude/agent-memory/` 的唯一證據來源是 `claude-directory` 頁，**那頁不在 `SOURCES` 裡**。實測目前 baseline：

```
.claude/agent-memory         → 沒有任何來源提到
.claude/agent-memory-local   → 沒有任何來源提到
```

但 `--coverage` 顯示：

```
- **C-105** `.claude/agent-memory` ← claude-code/changelog, claude-code/memory, claude-code/settings
```

這是假的，靠寬鬆前綴比對被 `.claude/` 之類的 token 認領——正是 PR #14 的 C-102 要修的東西。**合併 #14 之後，C-105 才會正確顯示成盲區。**

問題不在你判斷錯，而在**順序**：你的 plan §2.1.4 已經計畫補這個來源，但這輪在**來源還沒補之前就先登記了主張**。結果是這條主張目前處於「登記了、上游改掉沒人會知道、而且報表還告訴你有在看」的狀態。

**建議**：二選一。

1. 先做 plan M1 的 `claude-directory.md` 來源，再登記 C-105；或
2. 維持現在的登記，但在 C-105 的主張欄明寫「**本條的唯一依據來源尚未納入監控，屬盲區**；`--coverage` 在 PR #14 合併前會誤報為有涵蓋」。

我傾向 2（不要為了順序而把已查證的事實壓著不登記），但**註記是必要的**，否則這條主張會帶著假的安心感躺在帳本裡。

```python
# 六條新規則的逐條 mutation（預期 6/6 PASS）
import re, io, subprocess, tempfile, pathlib, os
s = io.open("skills/ai-git-ignore-strategy/claude/SKILL.md", encoding="utf-8").read()
tpl = [b for b in re.findall(r"(?ms)^```[a-zA-Z]*\n(.*?)^```$", s) if ".claude/*" in b][0]

def blocked(rule_removed, probe):
    mutant = tpl.replace(rule_removed, "") if rule_removed else tpl
    d = tempfile.mkdtemp()
    env = os.environ.copy()
    env["GIT_CONFIG_NOSYSTEM"] = "1"
    env["GIT_CONFIG_GLOBAL"] = os.devnull
    subprocess.run(["git", "init", "-q", d], env=env, stdout=subprocess.DEVNULL)
    pathlib.Path(d, ".gitignore").write_text(mutant, encoding="utf-8")
    return subprocess.run(
        ["git", "-c", f"core.excludesFile={os.devnull}",
         "check-ignore", "--no-index", "-q", "--", probe],
        cwd=d, env=env).returncode == 0

cases = [("!.claude/CLAUDE.md\n", ".claude/CLAUDE.md", False),
         ("!.claude/AGENTS.md\n", ".claude/AGENTS.md", False),
         ("!.claude/hooks/\n", ".claude/hooks/block-rm.sh", False),
         ("!.claude/agent-memory/\n", ".claude/agent-memory/r/MEMORY.md", False),
         ("**/.claude/agent-memory-local/\n", "apps/web/.claude/agent-memory-local/r/MEMORY.md", True),
         ("CLAUDE.local.md\n", "CLAUDE.local.md", True)]
for rule, probe, want in cases:
    base, mut = blocked(None, probe), blocked(rule, probe)
    print("PASS" if base == want and mut != want else "FAIL", rule.strip(), probe)
```
